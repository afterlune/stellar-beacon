# 数字空间 Agent 威胁模型

- 版本：2026-09-05
- 范围：公开 Agent、Eino/Provider、RAG、审核、持久任务、媒体内容、Companion 协议和管理控制面
- 目标：在任何公开能力放量前，明确攻击面、控制措施和阻断条件

## 信任边界

```text
用户/Companion
       │
       ├─ 公开 HTTP / SSE
       └─ Companion space API
              ▼
         Gin facade / middleware
              ▼
       application policy + domain port
          ├─ PostgreSQL 事实/审计
          ├─ Redis 短期状态/限流
          └─ infra Eino / Provider / Meili / Storage
```

- 人类后台会话和 Casbin 是控制面身份；Companion 使用独立的 `agent/moonfei` 主体和机器作用域。
- `app/application` 不持有 Provider SDK、数据库、缓存、搜索或对象存储类型。
- 公开内容是外部不可信资料，不是系统指令；模型不得把正文中的指令当成权限。

## 主要威胁与控制

### Prompt 注入与数据外泄

攻击者可在文章、评论、媒体描述、搜索结果或 Companion 发布内容中写入指令，诱导 Agent 泄露 Prompt、凭据、私有内容或执行管理动作。

控制：公开内容和检索结果标记为不可信资料；工具使用固定白名单；系统指令与内容分离；响应不输出思维链、Prompt、token、Provider 参数、SQL 参数或内部身份；生成内容进入审核。

### 身份混淆与工具越权

攻击者可伪造 `actor_id`、重放 token、利用前端隐藏按钮或路径通配符访问管理能力。

控制：身份从认证上下文派生；人类 Casbin 与 Companion scope 分离；读写 token 分离且常量时间比较；主体必须存在、启用且作用域匹配；后端按精确资源和方法授权；文章、视频、评论、权限、配置和删除能力不进入 Companion 工具。

### SSRF、恶意媒体与浏览器执行

攻击者可提交内部地址、带用户信息的 URL、恶意 MIME、超大媒体或可执行内容。

控制：外链要求 HTTPS、白名单和长度限制；服务端不抓取 Companion 提交的媒体 URL；上传检查大小、类型和文件签名；前端使用 CSP、sandbox、referrer policy、懒加载和受控 iframe；错误页面不回显远端正文。

### 会话、隐私和日志

攻击者可跨用户读取会话、事件、时间胶囊或通过日志获取敏感信息。

控制：会话查询绑定所有者；事件使用稳定 envelope 和顺序号；敏感内容不进标准日志；日志采用 `log/slog` 并做字段白名单/脱敏；错误只暴露稳定错误码；后台任务使用 supervisor 生命周期。

### 成本滥用与可用性

攻击者可并发请求、制造长 Prompt、断开 SSE、触发重试风暴或重复写入。

控制：请求大小、并发、速率和预算限制；Context 贯穿 handler、service、repository 和 Provider；Provider 采用有界重试、熔断和取消传播；部分流输出后不自动重试；日志队列有界并对永久错误停止重试。

### 审核和副作用重放

攻击者可重复批准、重放发布请求、绕过审核或利用竞态产生重复内容。

控制：所有生成内容默认 `pending`；审核动作绑定会话、目标、内容摘要和有效期；数据库条件更新、唯一幂等键和审计记录共同约束副作用；Companion 发布只允许状态/梦境/电台追加。

### 索引生命周期和陈旧数据

删除、私密化、模型换维度或部分回填可能让旧内容继续可检索，或新旧向量混用。

控制：公开性过滤在源查询和索引流程都执行；模型/维度变化使用新版本 UID；回填先备份、再质量/P95 门禁、后原子切换；旧索引在观察期前不删除；应用启动不自动 provision、回填或 swap。

### 供应链与发布风险

未锁定镜像、泄露凭据、错误 Compose 项目或未经备份的生产切换可能造成数据和服务事故。

控制：依赖和镜像固定版本/digest；密钥只从环境变量注入；CI 执行测试、边界扫描、漏洞和 secret 检查；生产迁移、索引、MinIO 和 Caddy 切换分别审批、备份和准备回滚；`benetnasch-dev` 使用独立项目名、端口和卷。

## 发布阻断条件

以下任一项缺失都按“未验证”处理：

- Go/前端测试和边界检查失败；
- feature flag、RBAC、审计、预算或紧急开关未确认；
- 公开响应包含 secret、Prompt、私有身份或内部错误；
- 隔离联调、迁移、备份或回滚证据缺失；
- 使用 mock、旧索引或静态检查冒充真实 Provider、浏览器或生产指标。

## 残余风险

Provider 数据保留、训练策略和区域合规性需要根据供应商合同确认。真实设备性能、生产规模 P95、20 并发 SSE、生产索引切换和恢复演练不由本文件的单元测试证明。任何生产容器或数据操作都必须另开发布窗口。
