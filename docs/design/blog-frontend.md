# Stellar Beacon 前台视觉规范

前台采用「科幻编辑界面」：内容是主体，未来感来自精确的网格、信号状态和轻量运动，而不是大面积霓虹、玻璃卡片或装饰性渐变。

## 设计基线

- 默认主题为深石墨，亮色主题使用暖灰纸面；两套主题都必须保证正文、链接、表单和焦点状态可读。
- 主强调色为荧光黄绿，信息色为电蓝，警示色为橙色。渐变只用于极短的品牌标记，禁止作为大面积背景。
- 面板以直角、细边线和局部角标为主；不使用连续圆角卡片堆叠。
- 标题使用系统无衬线，时间、数量、路径、状态和快捷键使用等宽字体。
- 页面版心为流式宽度，正文阅读列限制在舒适字面宽度；移动端优先保证导航、图片和正文不横向溢出。

## 页面语言

- 首页是个人出版物入口：编辑型大标题、置顶文章信号台、精选内容、分类索引和文章流。
- 文章详情是阅读工作台：正文居中、目录和进度辅助阅读、评论与相邻文章保持同一内容轨道。
- 归档和标签是数据索引；说说是时间信号流；相册是响应式图像拼贴；友链是网络名录；关于是个人档案；留言是通信终端。
- 搜索、登录、个人中心、密码文章和 404 复用同一套控件和状态反馈。

## 文章页续读规则

- 同系列文章单独形成紧凑的系列上下文：展示系列名、当前进度和相邻文章，不在相关阅读中重复推荐。
- 相关阅读只推荐公开文章，按共享标签数量优先、同分类次之、发布时间新近度兜底排序，最多展示 3 篇。
- 规则匹配不足时用最新公开文章去重补位；不足 3 篇时按实际数量展示，不填充占位卡片。
- 系列上下文和相关阅读至少有一半进入视口并停留约 1 秒后记一次曝光；模块内链接点击分别记为系列续读或相关阅读点击。
- 续读事件只上报来源文章和事件类型，不记录账号、目标文章、浏览器身份或原始来源；点击率按曝光数聚合计算。

## 动效与性能

- `AmbientGrid.vue` 使用 Canvas 绘制低频网格和节点，只承担环境层，不参与交互和滚动定位。
- 页面不可见、移动端低性能场景和 `prefers-reduced-motion: reduce` 时暂停或降级动画。
- 不使用 WebGL，不劫持滚动，不依赖远程字体或远程装饰图片。
- 动画只服务于状态变化、图片聚焦、导航反馈和首屏信号脉冲。

## 组件约束

- 公共控件优先复用现有 Vue/Element Plus 行为，通过前台令牌统一外观。
- 所有按钮、输入框、菜单、弹窗和图片预览必须有键盘路径与可见焦点。
- 装饰性 Canvas、扫描线、角标必须标记为 `aria-hidden`，不能遮挡内容或点击区域。
- 业务接口、路由和数据字段不因视觉重做而改变。
